# Pırpır — Neon Kanat

Mobil için tek dokunuşlu, neon/synthwave temalı bir uçma oyunu. Bol parçacık efekti, ekran sallanması,
zoom vuruşları, yavaş çekim ölüm anı, kıl payı bonusu, kristal toplama ve kristallerle açılan karakterler.

- `game/index.html` — oyunun tamamı (tarayıcıda da açılıp oynanabilir)
- `android/` — oyunu tam ekran WebView içinde açan Android aktivitesi
- `tools/build_apk.sh` — Android SDK gerektirmeden `dist/pirpir.apk` üretir (JDK + Node/Playwright + Python 3 yeterli)
- `dist/pirpir.apk` — hazır APK (Android 7.0+)
